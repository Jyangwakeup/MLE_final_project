# 自身炸弹责任期物理回退的漏报修复

对v6做边界审计时构造了一个当前仍承担自身炸弹责任、四个出口被箱子堵住且炸弹即将爆炸的状态。原safety_decision正确返回物理WAIT回退，却因提前返回而把robust_guarantee_loss留为False；危险火焰存在但炸弹已从列表消失时同样漏报。此场景是有效输入的合成回归，不声称它已经在当前v6真实对局中出现，也不声称v6会从合法放弹证明进入它。

该行为违背ADR0004/0015的既有诊断定义：责任期内不存在可接受的完整时域动作，不能静默跳过保证丢失。修复仅在v6的物理回退分支、own_bomb_pending=True时补报opponent_fallback和robust_guarantee_loss；物理回退掩码、动作选择、搜索预算、超时计数和v5历史行为不变。不重新解释或删除任何旧失败记录。

通过真实safety_decision入口的测试先出现两项断言失败，再验证炸弹、火焰、对手单独危险、旧v5及有证明逃生的自身炸弹五种边界。失败诊断经过task4_worker.safety_failure入口会立即停止。26项相关测试通过（其中最后一项安全逃生反例随后纳入完整测试集）；原始最小复现也由RED变GREEN。完整测试结果待追加。

本修复在独立safety-pending-diagnostic worktree完成，未改变正在执行的c8c9770第二批工程测试。该批终止后才能将修复合入主安全worktree并登记后续来源；已有运行仍按自身源码身份报告，并额外审计是否出现pending+physical_fallback组合。

修复期间对既有v6工程日志与第二批尚未完成的日志做独立轨迹扫描，共264,181次决策，未见pending+physical_fallback或无证明放弹。partial_trace_audit.json明确为进行中的部分观察，不是第二批最终准入证据；合成漏洞与真实发生率分开报告。

完整unittest共436项，跳过1项，无失败，涵盖新增全部五项边界测试；见full_passed.log。修复只提高漏报检查的完整性，不声称减少实际死亡或改善模型得分。
