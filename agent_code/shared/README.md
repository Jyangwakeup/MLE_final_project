# Shared Pipeline

Place code here only when both models use it. The goal is for every model to
receive the same encoded state, rewards, logging, and evaluation procedure.

Suggested model contract:

```python
class AgentModel:
    def select_action(self, observation, training: bool) -> str: ...
    def observe(self, transition) -> None: ...
    def learn(self) -> dict: ...
    def save(self, path) -> None: ...
    def load(self, path) -> None: ...
```
